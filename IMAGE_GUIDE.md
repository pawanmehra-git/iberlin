## 🔄 How to Replace Images

### Method 1: Direct File Replacement (Recommended)
1. **Prepare your images** according to the specifications above
2. **Rename your files** to match the exact filenames in the images folder
3. **Replace the files** in the `images/` folder
4. **Refresh your website** to see the changes

### Method 2: Update File Paths
If you want to use different filenames:
1. **Add your images** to the `images/` folder
2. **Update the HTML file** (`index.html`) to reference your new filenames
3. **Update the JavaScript file** (`script.js`) for product images

## 🛠️ Image Optimization Tips

### Before Uploading:
1. **Compress images** to reduce file size while maintaining quality
2. **Use appropriate formats:**
   - JPG for photographs
   - PNG for logos with transparency
3. **Optimize for web** - aim for file sizes under 500KB each
4. **Test on different devices** to ensure images look good on mobile and desktop

### Recommended Tools:
- **Image Resizing:** Canva, Photoshop, GIMP, or online tools
- **Image Compression:** TinyPNG, ImageOptim, or online compressors
- **Format Conversion:** Online converters or image editing software

## 🔍 Troubleshooting

### Images Not Showing:
1. Check that filenames match exactly (case-sensitive)
2. Ensure images are in the `images/` folder
3. Verify file formats are correct (JPG/PNG)
4. Clear browser cache and refresh

### Images Look Blurry:
1. Check image dimensions match recommendations
2. Ensure images are high resolution
3. Verify images are properly compressed

### Images Load Slowly:
1. Compress images to reduce file size
2. Use appropriate image formats
3. Consider using WebP format for better compression

## 📱 Mobile Considerations

- All images are responsive and will scale automatically
- Test on mobile devices to ensure images look good
- Consider how images will appear on small screens
- Ensure text overlays (if any) remain readable

## 🎨 Design Tips

### Product Images:
- Use consistent lighting and background
- Show products from multiple angles if possible
- Include packaging in the shot
- Ensure products look appetizing and professional

### Partner Logos:
- Use high contrast colors
- Ensure logos are readable at small sizes
- Maintain consistent style across all partner logos
- Use transparent backgrounds when possible
